Parte 1 — Correlación vs. regresión: dos preguntas distintas

Pregunta: en un muestreo de macroalgas Rhodophyta, ¿está asociada la biomasa con la cobertura de sustrato rocoso colonizado?

La diferencia clave: la correlación es simétrica (da lo mismo el orden de las variables) y no produce una ecuación para predecir. La regresión asume una dirección (X predice Y) y entrega una ecuación para estimar Y en sitios no muestreados. Si la pregunta es “¿están relacionadas?”, corresponde una correlación; si es “¿cuánto cambia Y por cada unidad de X?” o “¿qué Y se esperaría en un sitio con este X?”, corresponde una regresión.

Cómo se lee la pendiente en escala log-log

La pendiente no significa “especies adicionales por hectárea”. En escala log-log se interpreta como una elasticidad: un aumento de 1 % en el área se asocia con un aumento de aproximadamente 0.31 % en la riqueza. Una forma más intuitiva es preguntarse qué pasa al duplicar el área:

# Factor por el que se multiplica la riqueza al duplicar el área
2^coef(mod_sp)[2]
log10(area_ha) 
      1.239726

Duplicar el área multiplica la riqueza esperada por 1.24 (+24 %). Como el IC 95 % de la pendiente (0.23–0.39) no incluye 0, hay evidencia de que la riqueza aumenta con el área del parche.

Nota

Otras transformaciones útiles según el tipo de dato: raíz cuadrada para conteos con varianza que crece con la media, logit para proporciones. La lógica es siempre la misma: buscar la escala en la que la relación sea aproximadamente lineal y los residuos se comporten mejor. Para conteos y datos binarios, la sesión de GLM ofrece una alternativa que evita transformar.

Antes de confiar en mod_sp, se revisan los supuestos con los cuatro gráficos que produce plot() sobre un objeto lm:

Cómo leer cada panel:

  1. Residuals vs Fitted: se busca un patrón (curva, embudo). Una nube sin forma clara apoya la linealidad y la homocedasticidad.
  2. Q-Q Residuals: los puntos deben seguir aproximadamente la diagonal (normalidad de los residuos).
  3. Scale-Location: la dispersión vertical debe ser pareja a lo largo del eje X (homocedasticidad).
  4. Residuals vs Leverage: señala observaciones con influencia desproporcionada; se vigilan los puntos que superan las líneas de distancia de Cook (0.5 y 1).

El panel 2 se complementa con una prueba formal de normalidad:

Independencia de los residuos

Como en el Taller 2, la independencia se asegura desde el diseño: parches espacialmente independientes, sin pseudorreplicación. No se verifica con un gráfico de residuos. Cuando las observaciones tienen un orden espacial o temporal (estaciones a lo largo de la costa, muestreos mensuales), puede complementarse con el estadístico de Durbin-Watson; su uso se muestra en la guía complementaria.

En regresión múltiple se reporta el R² ajustado (0.70), que penaliza el número de predictores; el R² simple (0.72) siempre aumenta al agregar variables, aunque no aporten.

Coeficientes parciales: ¿qué significa cada b ahora?

Cada coeficiente representa el efecto de esa variable manteniendo constante la otra:

  • b(temperatura) = 0.401: por cada grado adicional, el crecimiento aumenta 0.4 mm/año, comparando corales a la misma profundidad.
  • b(profundidad) = -0.075: por cada metro adicional, el crecimiento disminuye 0.075 mm/año, a temperatura constante.

¿Qué pasa si se ignora la profundidad?

# Modelo con un solo predictor
mod_temp <- lm(crecimiento ~ temperatura, data = coral)

      parcial = coef(mod_coral)["temperatura"])

# Correlación entre predictores
cor(coral$temperatura, coral$profundidad)

Con solo la temperatura, la pendiente es 0.31 y subestima el efecto (0.4 en el modelo múltiple). En esta muestra, por azar, las colonias más cálidas quedaron algo más profundas (r = 0.30), y la profundidad reduce el crecimiento: parte del efecto positivo de la temperatura queda “tapado” por el de la profundidad. Por eso el modelo múltiple es necesario y no bastan dos regresiones simples por separado.

TipCómo reportar el resultado

En la sección de resultados de un artículo o de la tesis, se reportan los coeficientes con su IC, el R² ajustado, la prueba global y el diagnóstico de colinealidad. Por ejemplo:

El crecimiento coralino aumentó con la temperatura (b = 0,40 mm/año por °C; IC 95 %: 0,30–0,50) y disminuyó con la profundidad (b = −0,075 mm/año por m; IC 95 %: −0,10 a −0,05) (regresión lineal múltiple, F2,29 = 37,8; p < 0,001; R² ajustado = 0,70; VIF = 1,10).

Parte 5 — Multicolinealidad: ¿se puede confiar en cada coeficiente por separado?

Cuando dos predictores están muy correlacionados entre sí, el modelo no puede separar el efecto de cada uno y los coeficientes se vuelven inestables. El Factor de Inflación de Varianza (VIF) lo cuantifica: para cada predictor, se regresa contra los demás y se usa el r² de esa regresión auxiliar:

\[VIF_j = \frac{1}{1 - r^2_j}\]

Aplicando la fórmula, se construye la función a mano:

# VIF calculado a mano
vif_manual <- function(modelo) {
  predictores <- all.vars(formula(modelo))[-1]
  datos <- model.frame(modelo)
  sapply(predictores, function(v) {
    otros <- setdiff(predictores, v)
    f <- reformulate(otros, response = v)
    r2 <- summary(lm(f, data = datos))$r.squared
    1 / (1 - r2)
  })
}

vif_manual(mod_coral)
temperatura profundidad 
   1.099086    1.099086

El paquete car hace este cálculo automáticamente con vif(); se puede usar para verificar el cálculo manual:

# VIF con el paquete car
vif(mod_coral)

   1.099086    1.099086

VIF ≈ 1.1 en ambos predictores (con dos predictores el VIF es idéntico para los dos, porque ambos dependen de la misma correlación). Está muy cerca de 1: la correlación de 0.30 basta para modificar la pendiente simple (coeficientes parciales), pero no infla de forma apreciable la varianza de los coeficientes. Como regla práctica, VIF > 5–10 es señal de alerta y motivo para reconsiderar el modelo (quitar un predictor, combinarlos o rediseñar el muestreo).

Parte 6 — Selección de modelos con AIC

Pregunta: ¿Mejora el modelo al agregar un tercer predictor que, en teoría, también podría influir en el crecimiento: la turbidez del agua?

# Reproducibilidad
set.seed(77)

# Turbidez del agua (NTU)
coral$turbidez <- round(runif(n, 1, 12), 1)

# Modelos candidatos
mod_prof <- lm(crecimiento ~ profundidad, data = coral)
mod_full <- lm(crecimiento ~ temperatura + profundidad + turbidez, data = coral)

El modelo temperatura + profundidad tiene el AIC más bajo, aunque el modelo con turbidez tiene un r² apenas mayor: el r² siempre sube al agregar predictores, mientras que el AIC penaliza la complejidad que no aporta. La diferencia es de solo 1.4 puntos (ΔAIC < 2, soporte similar), así que la decisión se apoya en la parsimonia: se prefiere el modelo más simple.

Como los modelos están anidados, también puede usarse una prueba F:

Parte 7 — Planear antes de salir a campo: potencia y tamaño de muestra

Las Partes 2 a 6 analizaron datos ya colectados. Esta sección responde esta pregunta: ¿cuántas unidades experimentales (réplicas, n) se necesitan para detectar, con una potencia razonable, la regresión requerida? Es la misma lógica de power.t.test() de la Semana 1 con la inferencia estadística.

# Paquete para potencia con tamaños de efecto de Cohen
library(pwr)

# Tamaño del efecto f² de Cohen (global si R2_A = 0; parcial si se da R2_A)
f2_cohen <- function(R2_AB, R2_A = 0) (R2_AB - R2_A) / (1 - R2_AB)

# pwr.f2.test() devuelve v (gl del error), no n
n_desde_v <- function(v, u) ceiling(v) + u + 1

NotaElementos de la prueba

n = tamaño de la muestra o n.º de unidades experimentales.
u = predictores (xi) que se prueban (1 o 2 variables en la tabla).
v = grados de libertad del error. v = n − u − 1. Entonces n = ⌈v⌉ + u + 1.
f² = tamaño del efecto. f² = R² / (1 − R²). Con R² = 0.30, los predictores explican 0.30 frente a 0.70 de residuo, y f² = 0.43.
R² = proporción de la variación de Y que explican los predictores.

7.2 Regresión múltiple: ¿qué se quiere detectar?

Con dos predictores (profundidad y MO) hay dos preguntas distintas, que cambian u y f²:

#    Piloto: R² = 0.20 con la profundidad sola; 0.30 con profundidad + MO

[1] 57

La pregunta global pide 26 estaciones; la parcial, 57. La segunda es la pregunta real de casi todos los proyectos («¿importa la MO una vez controlada la profundidad?») y es la que debe orientar el diseño. Usa los mismos dos modelos anidados que compara anova() en la Parte 6.

ImportanteNo se planea con el r² del propio estudio

Calcular la potencia con el r² que salió del análisis («potencia observada») es circular: solo repite el valor p.

# Función de verificación
checklist_regresion <- function(modelo) {
  s <- summary(modelo)
  cat("r² =", round(s$r.squared, 3), "| r² ajustado =", round(s$adj.r.squared, 3), "\n")
  cat("IC 95 % de los coeficientes (¿excluyen 0?):\n")
  print(round(confint(modelo), 3))
  cat("Normalidad de residuos (Shapiro): p =", round(shapiro.test(resid(modelo))$p.value, 3), "\n")
  cat("Máxima distancia de Cook:", round(max(cooks.distance(modelo)), 2),
      ifelse(max(cooks.distance(modelo)) > 1, "-> revisar observación influyente", "-> OK"), "\n")
  if (length(coef(modelo)) > 2) {
    cat("VIF:\n"); print(round(vif_manual(modelo), 2))
  }
}

Antes de reportar cualquier modelo de regresión, conviene verificar:

  • ¿La relación es lineal (o se transformó para que lo sea)?
  • ¿Se revisaron los residuos (normalidad, homocedasticidad) y las observaciones influyentes?

## Parte 1 — Correlación vs. regresión: dos preguntas distintas {#sec-correlacion}

**La diferencia clave:** la correlación es simétrica (da lo mismo el orden de las variables) y no produce una ecuación para predecir. La regresión asume una dirección (X predice Y) y entrega una ecuación para estimar Y en sitios no muestreados. Si la pregunta es *"¿están relacionadas?"*, corresponde una correlación; si es *"¿cuánto cambia Y por cada unidad de X?"* o *"¿qué Y se esperaría en un sitio con este X?"*, corresponde una regresión.

**Para discutir:** si se intercambia el orden de las variables, ¿cambia el valor de r? ¿Y la pendiente de `lm(biomasa_gm2 ~ cobertura_pct)` frente a la de `lm(cobertura_pct ~ biomasa_gm2)`? Se puede comprobar en R.

### Cómo se lee la pendiente en escala log-log

La pendiente no significa "especies adicionales por hectárea". En escala log-log se interpreta como una **elasticidad**: un aumento de 1 % en el área se asocia con un aumento de aproximadamente `r round(coef(mod_sp)[2], 2)` % en la riqueza. Una forma más intuitiva es preguntarse qué pasa al **duplicar el área**:

```{r}
# Factor por el que se multiplica la riqueza al duplicar el área
2^coef(mod_sp)[2]
```

Duplicar el área multiplica la riqueza esperada por `r round(2^coef(mod_sp)[2], 2)` (+`r round(100 * (2^coef(mod_sp)[2] - 1))` %). Como el IC 95 % de la pendiente (`r round(confint(mod_sp)[2, 1], 2)`–`r round(confint(mod_sp)[2, 2], 2)`) no incluye 0, hay evidencia de que la riqueza aumenta con el área del parche.

::: callout-note
Otras transformaciones útiles según el tipo de dato: **raíz cuadrada** para conteos con varianza que crece con la media, **logit** para proporciones. La lógica es siempre la misma: buscar la escala en la que la relación sea aproximadamente lineal y los residuos se comporten mejor. Para conteos y datos binarios, la sesión de GLM ofrece una alternativa que evita transformar.
:::

```{r}
set.seed(194)

temperatura <- round(runif(n, 25, 31), 1)
profundidad <- round(runif(n, 2, 25), 1)

# Generar crecimiento
crecimiento <- round(-8.70 + 0.40 * temperatura - 0.08 * profundidad + rnorm(n, 0, 0.45), 2)

# Crear base de datos
coral <- data.frame(colonia = paste0("C", 1:n), temperatura, profundidad, crecimiento)
```


En regresión múltiple se reporta el **R² ajustado** (`r format(round(summary(mod_coral)$adj.r.squared, 2), nsmall = 2)`), que penaliza el número de predictores; el R² simple (`r round(summary(mod_coral)$r.squared, 2)`) siempre aumenta al agregar variables, aunque no aporten.

### Coeficientes parciales: ¿qué significa cada b ahora? {#sec-parciales}

Cada coeficiente representa el efecto de esa variable **manteniendo constante** la otra:

- b(temperatura) = `r round(coef(mod_coral)["temperatura"], 3)`: por cada grado adicional, el crecimiento aumenta `r round(coef(mod_coral)["temperatura"], 2)` mm/año, **comparando corales a la misma profundidad**.
- b(profundidad) = `r round(coef(mod_coral)["profundidad"], 3)`: por cada metro adicional, el crecimiento disminuye `r abs(round(coef(mod_coral)["profundidad"], 3))` mm/año, **a temperatura constante**.

¿Qué pasa si se ignora la profundidad?

```{r}
# Modelo con un solo predictor
mod_temp <- lm(crecimiento ~ temperatura, data = coral)

# Comparar la pendiente simple con la parcial
rbind(simple = coef(mod_temp)["temperatura"],
      parcial = coef(mod_coral)["temperatura"])

# Correlación entre predictores
cor(coral$temperatura, coral$profundidad)
```

Con solo la temperatura, la pendiente es `r round(coef(mod_temp)["temperatura"], 2)` y **subestima** el efecto (`r round(coef(mod_coral)["temperatura"], 2)` en el modelo múltiple). En esta muestra, por azar, las colonias más cálidas quedaron algo más profundas (r = `r format(round(cor(coral$temperatura, coral$profundidad), 2), nsmall = 2)`), y la profundidad reduce el crecimiento: parte del efecto positivo de la temperatura queda "tapado" por el de la profundidad. Por eso el modelo múltiple es necesario y no bastan dos regresiones simples por separado.

::: callout-tip
### Cómo reportar el resultado

En la sección de resultados de un artículo o de la tesis, se reportan los coeficientes con su IC, el R² ajustado, la prueba global y el diagnóstico de colinealidad. Por ejemplo:

> El crecimiento coralino aumentó con la temperatura (b = 0,40 mm/año por °C; IC 95 %: 0,30–0,50) y disminuyó con la profundidad (b = −0,075 mm/año por m; IC 95 %: −0,10 a −0,05) (regresión lineal múltiple, F~2,29~ = 37,8; p \< 0,001; R² ajustado = 0,70; VIF = 1,10).

Esta estructura es la que se espera en la Evidencia 1.
:::

## Parte 5 — Multicolinealidad: ¿se puede confiar en cada coeficiente por separado? {#sec-vif}

Cuando dos predictores están muy correlacionados entre sí, el modelo no puede separar el efecto de cada uno y los coeficientes se vuelven inestables. El **Factor de Inflación de Varianza (VIF)** lo cuantifica: para cada predictor, se regresa contra los demás y se usa el r² de esa regresión auxiliar:

$$VIF_j = \frac{1}{1 - r^2_j}$$

Aplicando la fórmula, se construye la función a mano:

```{r}
# VIF calculado a mano
vif_manual <- function(modelo) {
  predictores <- all.vars(formula(modelo))[-1]
  datos <- model.frame(modelo)
  sapply(predictores, function(v) {
    otros <- setdiff(predictores, v)
    f <- reformulate(otros, response = v)
    r2 <- summary(lm(f, data = datos))$r.squared
    1 / (1 - r2)
  })
}

vif_manual(mod_coral)
```

El paquete `car` hace este cálculo automáticamente con `vif()`; se puede usar para verificar el cálculo manual:

```{r}
# VIF con el paquete car
vif(mod_coral)
```

VIF ≈ `r round(vif_manual(mod_coral)[1], 2)` en ambos predictores (con dos predictores el VIF es idéntico para los dos, porque ambos dependen de la misma correlación). Está muy cerca de 1: la correlación de `r format(round(cor(coral$temperatura, coral$profundidad), 2), nsmall = 2)` basta para modificar la pendiente simple ([coeficientes parciales](#sec-parciales)), pero no infla de forma apreciable la varianza de los coeficientes. Como regla práctica, **VIF \> 5–10** es señal de alerta y motivo para reconsiderar el modelo (quitar un predictor, combinarlos o rediseñar el muestreo).

**Para discutir (RA1):** en el mar, la temperatura suele disminuir con la profundidad. Si el muestreo solo incluyera sitios con una termoclina marcada, ¿qué pasaría con el VIF y con la interpretación de cada coeficiente? ¿Cómo lo evitaría el diseño de muestreo?

## Parte 7 — Planear antes de salir a campo: potencia y tamaño de muestra {#sec-potencia}

```{r, echo=FALSE, message=FALSE, warning=FALSE}
#| out-width: "0.8\\linewidth"
#| fig-align: left
#| fig-pos: 'H'
knitr::include_graphics("figuras_portadas/portada_potencia.jpg")
```


Las Partes 2 a 6 analizaron datos ya colectados. Esta sección responde esta pregunta: **¿cuántas unidades experimentales (réplicas, n) se necesitan para detectar, con una potencia razonable, la regresión requerida?** Es la misma lógica de `power.t.test()` de la Semana 1 con la inferencia estadística.

```{r}
# Paquete para potencia con tamaños de efecto de Cohen
library(pwr)

# Tamaño del efecto f² de Cohen (global si R2_A = 0; parcial si se da R2_A)
f2_cohen <- function(R2_AB, R2_A = 0) (R2_AB - R2_A) / (1 - R2_AB)

# pwr.f2.test() devuelve v (gl del error), no n
n_desde_v <- function(v, u) ceiling(v) + u + 1
```

### 7.1 Regresión simple: un predictor

**Pregunta de diseño:** en fondos blandos, ¿cuántas estaciones se necesitan para encontrar que la diversidad funcional (FD) disminuya con la materia orgánica (MO)? Un piloto o la literatura sugiere un R² cercano a 0.30.

```{r}
# Tamaño del efecto esperado
f2_simple <- f2_cohen(0.30)
f2_simple

# Potencia de 80 % con α = 0.05 y un predictor (u = 1)
plan_simple <- pwr.f2.test(u = 1, 
                           f2 = f2_simple, 
                           sig.level = 0.05, 
                           power = 0.80)
plan_simple

# Tamaño de muestra
n_desde_v(plan_simple$v, u = 1)
```

Se necesitan unas **21 estaciones**. `v` son los grados de libertad del error, y n = ⌈v⌉ + u + 1.

Para interpretar los tamaños de efecto de referencia, conviene traducirlos a R²:

```{r}
#| html-table-processing: none
#| echo: false

# Referencias de Cohen, su R² equivalente y el n que piden con u = 1 y u = 2
ref <- data.frame(efecto = c("pequeño", "mediano", "grande"),
                  f2 = c(0.02, 0.15, 0.35))

ref$R2 <- round(ref$f2 / (1 + ref$f2), 2)

ref$n_u1 <- sapply(ref$f2, 
                   function(x) 
                     n_desde_v(pwr.f2.test(u = 1, f2 = x, 
                                           power = 0.80)$v, 1))
ref$n_u2 <- sapply(ref$f2, 
                   function(x) 
                     n_desde_v(pwr.f2.test(u = 2, f2 = x, 
                                           power = 0.80)$v, 2))

ref %>%
  kbl(booktabs = TRUE, longtable = FALSE) %>%
  kable_classic(full_width = F) %>%
  kableExtra::row_spec(0, bold = TRUE)
```

::: callout-note
### Elementos de la prueba

**n** = tamaño de la muestra o n.º de unidades experimentales.\
**u** = predictores (xi) que se prueban (1 o 2 variables en la tabla).\
**v** = grados de libertad del error. v = n − u − 1. Entonces n = ⌈v⌉ + u + 1.\
**f²** = tamaño del efecto. f² = R² / (1 − R²). Con R² = 0.30, los predictores explican 0.30 frente a 0.70 de residuo, y f² = 0.43.\
**R²** = proporción de la variación de Y que explican los predictores.
:::

### 7.2 Regresión múltiple: ¿qué se quiere detectar?

Con dos predictores (profundidad y MO) hay dos preguntas distintas, que cambian u y f²:

```{r}
# 1) ¿El modelo completo explica algo? f² global, u = número de predictores
plan_global <- pwr.f2.test(u = 2, f2 = f2_cohen(0.30), power = 0.80)
n_desde_v(plan_global$v, u = 2)

# 2) ¿La MO aporta por encima de la profundidad? f² parcial, u = 1
#    Piloto: R² = 0.20 con la profundidad sola; 0.30 con profundidad + MO
f2_parcial <- f2_cohen(R2_AB = 0.30, R2_A = 0.20)
f2_parcial
plan_parcial <- pwr.f2.test(u = 1, f2 = f2_parcial, power = 0.80)
n_desde_v(plan_parcial$v, u = 1)
```

La pregunta global pide **26** estaciones; la parcial, **57**. La segunda es la pregunta real de casi todos los proyectos («¿importa la MO una vez controlada la profundidad?») y es la que debe orientar el diseño. Usa los mismos dos modelos anidados que compara `anova()` en la [Parte 6](#sec-aic).

::: callout-important
### No se planea con el r² del propio estudio

Calcular la potencia con el r² que salió del análisis («potencia observada») es circular: solo repite el valor p.

```{r}
# El error: usar el r² observado del manglar
r2_obs <- summary(mod_sp)$r.squared
n_desde_v(pwr.f2.test(u = 1, f2 = f2_cohen(r2_obs), power = 0.80)$v, u = 1)
```

Con r² = `r round(summary(mod_sp)$r.squared, 3)` saldría n = 5, una cifra absurda. Para planear se usa un R² de un piloto o de la literatura, o el efecto mínimo con relevancia biológica.
:::

::: callout-tip
### Para profundizar (guía complementaria)

## Parte 8 — Lista de verificación antes de reportar el modelo {#sec-checklist}

```{r}
# Función de verificación
checklist_regresion <- function(modelo) {
  s <- summary(modelo)
  cat("r² =", round(s$r.squared, 3), "| r² ajustado =", round(s$adj.r.squared, 3), "\n")
  cat("IC 95 % de los coeficientes (¿excluyen 0?):\n")
  print(round(confint(modelo), 3))
  cat("Normalidad de residuos (Shapiro): p =", round(shapiro.test(resid(modelo))$p.value, 3), "\n")
  cat("Máxima distancia de Cook:", round(max(cooks.distance(modelo)), 2),
      ifelse(max(cooks.distance(modelo)) > 1, "-> revisar observación influyente", "-> OK"), "\n")
  if (length(coef(modelo)) > 2) {
    cat("VIF:\n"); print(round(vif_manual(modelo), 2))
  }
}

# Aplicar a los dos modelos del taller
checklist_regresion(mod_sp)
checklist_regresion(mod_coral)
```

Antes de reportar cualquier modelo de regresión, conviene verificar:

- ¿La relación es lineal (o se transformó para que lo sea)?
- ¿Se revisaron los residuos (normalidad, homocedasticidad) y las observaciones influyentes?
- ¿El diseño garantiza la independencia de las observaciones?
- ¿El IC 95 % de cada pendiente de interés excluye 0?
- ¿Se interpretó r² (o R² ajustado) como variación explicada y no como causalidad?
- ¿Se evaluó el VIF y se compararon modelos candidatos con AIC, sin extrapolar fuera del rango observado?

A continuación se presentan el contexto y los datos; la decisión se toma con los mismos criterios de la lista de verificación ([Parte 8](#sec-checklist)).

::: callout-note
### El contexto

Un equipo que trabaja en el cultivo experimental de juveniles de langosta espinosa (*Panulirus argus*) necesita **estimar el peso de cada individuo a partir de su longitud cefalotorácica (LC)**, para no tener que pesarlos en cada revisión. Se midieron y pesaron 30 individuos. Además, se quiere saber si el crecimiento es **isométrico**: si el peso aumenta con el cubo de la talla (peso ∝ LC³), la forma corporal se mantiene al crecer.
:::

Antes de escribir código, conviene responder:

1.  ¿Es una pregunta de correlación o de regresión? ¿Cuál es la variable respuesta?
2.  El peso depende del volumen del animal, y el volumen crece con el cubo de la talla. ¿Qué forma se espera en la relación talla-peso, y en qué escala se volvería lineal?
3.  Si el crecimiento es isométrico, ¿qué valor debería tener la pendiente en esa escala?

A continuación se simulan los datos y se ajusta, primero, el modelo más ingenuo:

```{r}
#| html-table-processing: none

# Reproducibilidad
set.seed(2026)

# Número de individuos
n <- 30

# Longitud cefalotorácica (mm)
talla_lc <- round(runif(n, 40, 95), 1)

# Peso (g) con una relación alométrica
peso_g <- round(0.0033 * talla_lc^2.7 * exp(rnorm(n, 0, 0.10)))

# Crear base de datos
langosta <- data.frame(individuo = paste0("L", 1:n), talla_lc, peso_g)

# Tabla con los datos

  kableExtra::row_spec(0, bold = TRUE)
```

Con el r² y esos dos gráficos en mano, se debe tomar una decisión **antes de seguir leyendo**: ¿se reporta el modelo lineal tal como está, o se ajusta otro? Si es otro, ¿cuál?

::: {.callout-tip collapse="true"}
### Verificación del razonamiento (clic para revelar)

**1. Correlación o regresión:** es regresión. El objetivo es **predecir** el peso a partir de la talla, así que el peso es la respuesta y la talla el predictor.

**2. Forma esperada:** el peso es proporcional al volumen, que crece aproximadamente con el cubo de la talla. La relación es una **ley de potencia** (peso = a·LC\^b), igual que la relación especie-área de la [Parte 2](#sec-simple), y se vuelve lineal en escala log-log: log(peso) = log(a) + b·log(LC).

**3. Pendiente esperada:** con crecimiento isométrico, b = 3.

**El resultado del modelo ingenuo:** r² = `r round(summary(mod_lineal)$r.squared, 2)`, muy alto, pero los residuos forman una **curva** (positivos en los extremos, negativos en el centro) y un **embudo** (más dispersión en los animales grandes), y la prueba de Breusch-Pagan confirma la heterocedasticidad. **Un r² alto no valida un modelo mal especificado.**

Se ajusta el modelo log-log:

```{r}
# Ajustar modelo alométrico
mod_alom <- lm(log10(peso_g) ~ log10(talla_lc), data = langosta)

# Consultar resultados
summary(mod_alom)

# Intervalos de confianza
confint(mod_alom)
```

```{r}
#| fig-width: 8
#| fig-height: 7
# Diagnóstico del modelo alométrico
par(mfrow = c(2, 2))
plot(mod_alom)
par(mfrow = c(1, 1))

# Homocedasticidad y normalidad
ncvTest(mod_alom)
shapiro.test(resid(mod_alom))
```

Los residuos ya no muestran curva ni embudo, y ninguna prueba detecta problemas.

**¿Es isométrico el crecimiento?** Aquí la hipótesis nula no es b = 0 (que el peso no dependa de la talla, algo obvio), sino **b = 3**. Se contrasta con un t-test sobre la pendiente, la misma lógica de la Semana 1:

```{r}
# Pendiente y su error estándar
b  <- coef(mod_alom)[2]
ee <- summary(mod_alom)$coefficients[2, 2]

# t para H0: b = 3
t_iso <- (b - 3) / ee
p_iso <- 2 * pt(-abs(t_iso), df = mod_alom$df.residual)

c(b = unname(b), t = unname(t_iso), p = unname(p_iso))
```

b = `r round(coef(mod_alom)[2], 2)` (IC 95 %: `r round(confint(mod_alom)[2, 1], 2)`–`r round(confint(mod_alom)[2, 2], 2)`). Como el intervalo **no incluye 3** (p = `r format(signif(p_iso, 2), scientific = FALSE)`), se rechaza la isometría: el crecimiento es **alométrico negativo**, es decir, los individuos grandes pesan menos de lo que predeciría una forma corporal constante.

Para usar el modelo en el cultivo, la ecuación se retransforma a la escala original:

```{r}
# Coeficiente a de peso = a·LC^b
a <- 10^coef(mod_alom)[1]
c(a = unname(a), b = unname(b))

# Peso esperado de un juvenil de 60 mm de LC
a * 60^b
```

El peso esperado de un juvenil de 60 mm de LC es de unos `r round(10^coef(mod_alom)[1] * 60^coef(mod_alom)[2])` g. Solo es válido dentro del rango de tallas medido (`r min(langosta$talla_lc)`–`r max(langosta$talla_lc)` mm).
:::
