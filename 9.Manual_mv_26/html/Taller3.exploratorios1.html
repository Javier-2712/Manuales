Taller3. Exploratorios_mv

Resumen de las actividades

📋 Instrucciones

Este taller enfatiza el entrenamiento de gráficos exploratorios (univariados, bivariados y multivariados), orientado en la identificación de patrones (p. ej. gradientes, dominancia de taxones, heterogeneidad ambiental, asociaciones bióticas y abióticas, identificación de valores atípicos) a partir de una manipulación apropiada de los datos.

La lógica de trabajo consiste en (1) preparar y revisar datos, (2) elegir figuras que responden a la pregunta definida, (3) interpretar los patrones y (4) documentar los resultados.

Los ejercicios que se desarrollan en este taller emplean bases de datos de ensamblajes de (1) macroinvertebrados acuáticos de ecosistemas fluviales y (2) de mesozooplancton en ambientes estuarinos, enfocado a la representación gráfica de los datos que busca:

  • Identificar cambios en la estructura y composición del ensamblaje de cada grupo evaluado, en función de variables como salinidad, temperatura o estratificación vertical.

  • Explorar la distribución de grupos evaluados a lo largo de gradientes ambientales discretos o continuos.

  • Generar evidencia visual que oriente decisiones de muestreo en estudios similares, orientados al monitoreo o a la modelación ecológica.

Es así como el diseño estructura de figuras permite sintetizar relaciones complejas de manera comprensible permitiendo en estos casos guiados, pensar en potenciales decisiones de gestión ambiental, toma de decisiones y enfoques asociados a la integridad ecológica o salud de sus ecosistemas. En este sentido, la visualización no solo apoya la inferencia científica, sino que fortalece el diálogo entre la investigación ecológica y la gestión ambiental, abordando a tres grandes estrategias de visualización:

  1. análisis de relaciones,
  2. comparación entre grupos o bloques de factores y
  3. síntesis multivariada mediante estrategias más avanzadas como las burbujas.
🔎 Visualizar es formular hipótesis preliminares.

Un gráfico no genera inferencia de causalidad, pero puede orientar estas preguntas:
- ¿Existe un gradiente estructurante del ensamblaje?
- ¿Hay segregación espacial de los taxones?
- ¿Se observan umbrales de tolerancia ambiental?
- ¿Existen valores atípicos que requieran verificación de los datos?

A. Caso guiado: Macroinvertebrados bentónicos fluviales

Este caso guiado consiste en analizar de forma gráfica a ensamblajes de macroinvertebrados bentónicos asociados a gradientes físico-químicos del río Gaira, en Santa Marta.

El objetivo se orienta en trasladar la lógica de la visualización ecológica a un contexto enfocado en comparar distribuciones que permitan identificar patrones de dominancia, explorar relaciones entre variables revela gradientes ambientales, y seleccionar representaciones adecuadas facilita la interpretación de la estructura del ensamblaje.

Este ejercicio consolida la visualización como una herramienta central para el análisis ecológico, permitiendo interpretar la organización de las comunidades biológicas en sistemas ambientalmente heterogéneos.

A continuación se muestra el procedimiento con lenguaje Tidyverse, para realizar una tabla con el resumen de diferentes insumos estadísticos, para cada grupo (cuencas) de la base de datos.

# Resumen estadístico "datos_resum"
datos_resum <- datos %>%        # Base de datos resumida
  group_by(cuenca) %>%          # Factor o variable agrupadora
  summarise(datos.m = mean(Ab),   # Media de cada grupo del factor
            datos.de  = sd(Ab),   # Desviacioes estándar de cada grupo
            datos.var = var(Ab),  # Varianzas de cada grupo

El siguiente procedimiento permitirá organizar la base de datos de tal forma que pueda ser utilizada en diseños multivariados. Normalmente encontrarémos las bases de datos en formato ancho, para esos casos, no será necesario realizar el siguiente procedimiento.

# Procesamiento para ajustar los datos en formato ancho
biol1 <-
  biol %>% 
  # Abreviaturas de los taxones
  mutate(Abrev = abbreviate(Groups, minlength = 4)) %>% 
  # Variables a factores
  mutate(across(c(Station, Size, Layers), as.factor)) %>% 
  # Agrupamiento para el formato ancho
  group_by(Station, Size, Layers) %>% 
  # Promedios de las variables ambientales
  summarize(
    across(c(Temperature, Salinity, Density), ~round(mean(.),2)),
  # Totales de las abundancias por cada factor
    Abundance = list(setNames(tapply(Abundance, Abrev,sum,
                                     default = 0), unique(Abrev))),
  # Corregir algunos errores del agrupamiento
    .groups = "drop") %>% 
  # Separar las abundancias en las columnas de cada taxon
  unnest_wider(Abundance) %>% 
  # Crear columna Ref, tomando iniciales de tres factores
  mutate(
    Ref = paste0(substr(Station, 1, 2),
               substr(Size, 1, 1),
               substr(Layers, 1, 1))) %>% 
  # Pasar la columna de referencia (consec) a la 1a columna
  select(Ref, everything()) %>% 
  # Crear la columna Ab con la suma de las columnas de taxones
  mutate(
  # Suma de las columnas especificadas (Ab)  
    Ab = rowSums(across(Qtgn:Otrs), na.rm = TRUE)
