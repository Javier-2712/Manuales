Guía complementos estudios de caso FD y PD

NotaArchivos que usa esta guía

Los libros principales deben estar en la misma carpeta de este .qmd: datos_peces.xlsx, datos_bosques.xlsx, datos_hormigas.xlsx y datos_copros.xlsx (hojas tax, rasgos, coord y amb). Los complementos son opcionales: los libros *_adicional.xlsx, el árbol moreau_bell_phylogeny_2013.nex (hormigas) y el archivo ATLANTIC_DUNG_BEETLE_TRAITS_revised.csv (coprófagos). Si alguno falta, el bloque que lo usa lo avisa con un mensaje y la guía sigue renderizando. Los bloques de rfishbase, fishtree, BIEN y V.PhyloMaker2 necesitan conexión a internet.

Para qué sirve esta guía

Los cuatro libros de Excel de los estudios de caso (hojas tax, rasgos, coord y amb) permiten calcular la diversidad taxonómica (TD) y la funcional (FD), pero ninguno trae filogenia, y dos siguen por debajo del mínimo de la asignatura (al menos 2 rasgos cuantitativos y 2 cualitativos): a hormigas le faltan los cualitativos y coprófagos tiene un solo cuantitativo, la biomasa. Esta guía reúne recursos abiertos para completar esos vacíos.

ImportanteLo que esta guía no resuelve

La guía resuelve problemas de datos: dónde completar rasgos, cómo construir un árbol cuando la base no trae filogenia y cómo alinear los nombres entre tablas. Las decisiones que se evalúan en el estudio de caso corresponden a cada grupo:

  • la pregunta ecológica y las unidades que se comparan;
  • los rasgos que entran al análisis y la justificación de cada uno;
  • las métricas y la estandarización por cobertura (B1 y B2);
  • la interpretación de TD, FD y PD y su integración en una sola respuesta.

La propuesta es trabajar con un piso común, que todos los grupos pueden alcanzar con los procedimientos de los talleres del curso, y un techo opcional, que depende de los recursos disponibles para cada grupo taxonómico.

NotaPor qué el piso de PD es un árbol taxonómico

Es el mismo recurso que se ensayó en el Taller 1: un árbol simplificado a partir de la clasificación, del que se obtiene la distancia cofenética. Su ventaja es que no excluye a las morfoespecies (sp., aff., cf.): se ubican en su género. Su límite es que las longitudes de rama no representan tiempo evolutivo, así que la PD resultante mide la distinción taxonómica, y así debe interpretarse.

Leer hojas de los libros adicionales

Los libros *_adicional.xlsx son opcionales. Esta función devuelve la hoja pedida o, si el libro o la hoja no están, un mensaje y NULL, para que el resto de la guía siga funcionando.

Código 
leer_adicional <- function(archivo, hoja) {
  if (!file.exists(archivo)) {
    message("No se encontró ", archivo, ": se omite la hoja '", hoja, "'.")
    return(NULL)
  }
  if (!hoja %in% readxl::excel_sheets(archivo)) {
    message("El libro ", archivo, " no tiene la hoja '", hoja, "'.")
    return(NULL)
  }
  readxl::read_excel(archivo, sheet = hoja)
}

Árbol taxonómico (piso de PD)

La función toma una tabla con una columna por nivel taxonómico, de mayor a menor, y devuelve un árbol con longitudes de rama de Grafen. Los nombres de especie deben ser únicos y coincidir exactamente con las columnas de tax.

Código 
arbol_taxonomico <- function(tabla, niveles) {
  # tabla: data.frame con una columna por nivel; la última es la especie
  # niveles: vector con los nombres de esas columnas, de mayor a menor
  # as.phylo() arma el árbol como texto Newick: los espacios en los nombres
  # se reemplazan por "_" durante la construcción y se restauran al final
  tabla <- as.data.frame(lapply(tabla[, niveles],
                                function(x) factor(gsub(" ", "_", trimws(x)))))
  formula_tax <- as.formula(paste("~", paste(niveles, collapse = "/")))
  arbol <- ape::as.phylo(formula_tax, data = tabla)
  arbol <- ape::compute.brlen(arbol, method = "Grafen")
  arbol$tip.label <- gsub("_", " ", arbol$tip.label)
  arbol
}

Con el árbol se obtienen los dos insumos que se usan en el curso. Se definen como función para aplicarla después sobre el árbol de cada grupo (ver la plantilla al final de la sección de coprófagos).

Código 
insumos_pd <- function(arbol) {
  # Distancia filogenética (cofenética) escalada a [0, 1], formato que usa Rao()
  d <- ape::cophenetic.phylo(arbol)
  d <- d / max(d)
  list(dist_filo = d,      # para Rao(dphyl = ...)
       arbol     = arbol)  # para iNEXT3D(diversity = "PD", PDtree = ...)
}

Completar una morfoespecie dentro de su género

Cuando se dispone de una filogenia de géneros (hormigas y coprófagos), cada especie o morfoespecie se agrega como una politomía dentro de la punta de su género.

Código 
expandir_generos <- function(arbol_generos, tabla, largo = 1) {
  # tabla: data.frame con columnas 'especie' y 'genero'
  faltan <- setdiff(unique(tabla$genero), arbol_generos$tip.label)
  if (length(faltan) > 0) warning("Géneros sin punta en el árbol: ",
                                  paste(faltan, collapse = ", "))
  arbol <- ape::keep.tip(arbol_generos,
                         intersect(unique(tabla$genero), arbol_generos$tip.label))
  for (g in intersect(unique(tabla$genero), arbol$tip.label)) {
    spp <- tabla$especie[tabla$genero == g]
    if (length(spp) == 1) {
      arbol$tip.label[arbol$tip.label == g] <- spp
    } else {
      estrella <- ape::stree(length(spp), type = "star", tip.label = spp)
      estrella$edge.length <- rep(largo, nrow(estrella$edge))
      arbol <- ape::bind.tree(arbol, estrella, where = which(arbol$tip.label == g))
    }
  }
  arbol
}
ImportanteChequeo obligatorio antes de calcular PD

Las especies de tax y las puntas del árbol deben ser el mismo conjunto. Si no lo son, se filtra tax al subconjunto común y se reporta qué quedó fuera, como indica el Taller 1.

Código 
chequeo_arbol <- function(arbol, tax) {
  spp_tax <- setdiff(colnames(tax), c("Sites", "Sites1"))
  list(en_tax_no_en_arbol = setdiff(spp_tax, arbol$tip.label),
       en_arbol_no_en_tax = setdiff(arbol$tip.label, spp_tax))
}

Rasgos incompletos: una regla sencilla

No se imputan valores con ceros. Si un rasgo cuantitativo falta para una especie, el orden de preferencia es: (1) medición propia o dato de la misma especie en otra fuente; (2) media del género en la misma fuente, declarada como tal en una columna de origen del dato; (3) excluir el rasgo si falta en más del 30 % de las especies.

Complemento FD

La hoja rasgos ya cumple el mínimo: dos rasgos cuantitativos (TrophicLevel y BodyLengthMax) y cinco binarios de dieta. Hay que tener en cuenta que la dieta varía poco, porque la mayoría de especies son invertívoras. La hoja rasgos_extra del libro adicional agrega rasgos que no se usaron en rasgos: posición en la columna de agua (Level_water), actividad diaria (Diel_activity), forma del cuerpo (Body_shape), aleta caudal, posición de la boca, profundidad máxima y relación de aspecto. Con ellos se supera el mínimo de rasgos sin buscar fuentes externas. Conviene revisar los vacíos de la relación de aspecto antes de usarla.

La TD se calcula con tax_completa, que incluye especies sin rasgos. Para esas especies, rfishbase puede aportar talla máxima y nivel trófico; las morfoespecies (sp.) se excluyen porque no están en FishBase:

Código 
library(rfishbase)
if (!is.null(tax_completa)) {
  sin_rasgos <- setdiff(colnames(tax_completa), c("Sites", "Sites1", rasgos$LatinName))
  sin_rasgos <- sin_rasgos[!grepl("sp\\.|aff\\.|cf\\.", sin_rasgos)]
  length(sin_rasgos)   # especies de tax_completa sin rasgos

  talla  <- rfishbase::species(sin_rasgos, fields = c("Species", "Length"))
  trofia <- rfishbase::ecology(sin_rasgos, fields = c("Species", "FoodTroph"))
}
Tip

Los valores de FishBase y los de Quimbayo et al. no son intercambiables sin revisar: se sugiere usar FishBase solo para las especies ausentes y marcar el origen de cada valor.

Complemento PD (techo): V.PhyloMaker2

V.PhyloMaker2 construye una filogenia a partir de un megaárbol de plantas vasculares. Necesita especie, género y familia, con familias actualizadas: la base trae Myrsinaceae, un nombre antiguo que el código cambia a Primulaceae. Si aparece otro aviso de clasificación, conviene revisar la familia con World Flora Online.

Código 
library(V.PhyloMaker2)
lista_bst <- data.frame(
  species = rasgos$LatinName,
  genus   = sub(" .*", "", rasgos$LatinName),
  # Myrsinaceae ya no se usa (APG IV la incluye en Primulaceae); sin este
  # cambio, phylo.maker() advierte que la clasificación no coincide
  family  = dplyr::recode(rasgos$Family, Myrsinaceae = "Primulaceae")
)

res <- V.PhyloMaker2::phylo.maker(sp.list = lista_bst,
                                  tree = GBOTB.extended.TPL,
                                  nodes = nodes.info.1.TPL,

arbol_bst <- res$scenario.3
arbol_bst$tip.label <- gsub("_", " ", arbol_bst$tip.label)

Complemento FD

Los cuatro rasgos (ojo, escapo, pata y longitud de Weber) están muy correlacionados. Para separar la forma del tamaño, se recomienda usar la longitud de Weber como rasgo de tamaño y los demás como proporciones:

Código 
rasgos_h <- rasgos %>%
  mutate(Ojo_rel    = Eye_length   / Weber_length,
         Escapo_rel = Scape_length / Weber_length,
         Pata_rel   = Leg_length   / Weber_length,
         Tamano_log = log(Weber_length)) %>%
  select(LatinName, Tamano_log, Ojo_rel, Escapo_rel, Pata_rel)

Los rasgos categóricos (dieta, estrategia de nidificación, dominancia) pueden asignarse por género con fuentes como la base GlobalAnts (Parr et al. 2017) o AntWiki, siempre en una tabla aparte con la fuente de cada valor. La base tiene 14 géneros: Atta, Azteca, Brachymyrmex, Camponotus, Cephalotes, Crematogaster, Dolichoderus, Dorymyrmex, Ectatomma, Gnamptogenys, Megalomyrmex, Myrmelachista, Pseudomyrmex y Solenopsis.

Complemento PD (techo): filogenia de géneros

El depósito de Dryad de Morais et al. (2026) incluye el archivo moreau_bell_phylogeny_2013.nex, con la filogenia de géneros de Moreau y Bell (2013), y el script phylogenetic_diversity__analysis.R de los autores. Como 40 de las 50 especies son morfoespecies, la PD se calcula a nivel de género con expandir_generos().

Código 
# Archivo del depósito de Dryad de Morais et al. (2026). Se descarga a mano
# y se guarda en la misma carpeta de este .qmd.
archivo_mb <- "moreau_bell_phylogeny_2013.nex"
tabla_h <- data.frame(especie = rasgos$LatinName, genero = rasgos$Genus)

if (file.exists(archivo_mb)) {
  arbol_mb <- ape::read.nexus(archivo_mb)
  if (inherits(arbol_mb, "multiPhylo")) arbol_mb <- arbol_mb[[1]]
  print(head(arbol_mb$tip.label))   # revisar el formato de las puntas

  # Una sola punta por género (sirve si las puntas son "Genero" o "Genero_especie")
  gen_tip  <- sub("_.*", "", arbol_mb$tip.label)
  arbol_mb <- ape::keep.tip(arbol_mb, arbol_mb$tip.label[!duplicated(gen_tip)])
  arbol_mb$tip.label <- sub("_.*", "", arbol_mb$tip.label)

  arbol_hormigas <- expandir_generos(arbol_mb, tabla_h)
} else {
  message("No se encontró ", archivo_mb,
          ": se usa el árbol taxonómico (piso de PD).")
  arbol_hormigas <- arbol_taxonomico(as.data.frame(rasgos),
                                     c("Subfamily", "Genus", "LatinName"))
}

El vacío principal: un rasgo cuantitativo

La tesis trae gremio de relocalización y dieta, pero ningún rasgo cuantitativo: con esos dos rasgos, las 21 especies caen en 5 combinaciones. El tamaño corporal es el rasgo más importante que falta, porque se relaciona con la cantidad de excremento que remueve cada especie (Giménez Gómez y Tonelli 2022). Por eso, la hoja rasgos de datos_copros.xlsx ya incluye la biomasa corporal tomada de ATLANTIC DUNG BEETLE TRAITS (columnas Biomass_g, Biomass_log10, Biomass_level y Biomass_source), además de la tribu (Tribe). Es un solo rasgo cuantitativo y, en 18 de las 21 especies, una media de género; las fuentes para mejorarlo, en orden de preferencia, son:

  1. Medición propia de ejemplares en una colección de referencia, si se dispone de los géneros de la base.
  2. Literatura taxonómica de la especie, por ejemplo las revisiones de Eurysternus (Génier 2009) y Coprophanaeus (Edmonds y Zídek 2010), ya citadas en la tesis.
  3. ATLANTIC DUNG BEETLE TRAITS (Ribeiro Anunciação et al. 2025), la fuente de los valores actuales: a nivel de especie cuando coincide y, si no, como media del género.

Es una base de Mata Atlántica, no del bosque seco del Caribe: es probable que pocas de las 21 especies de Chimichagua coincidan y que la mayoría de valores sean medias de género. Eso tiene dos consecuencias: (1) seis de las siete especies de Canthon reciben el mismo valor, y (2) un rasgo asignado por género se parece mucho a la información filogenética, lo que puede inflar la coincidencia entre FD y PD. La biomasa varía unas 150 veces entre los géneros con datos propios (de 0,006 g en Uroxys a 0,88 g en Coprophanaeus), así que incluso a nivel de género separa bien a los escarabajos pequeños de los grandes. Dentro de Canthon, en cambio, varía unas 40 veces entre especies, y esa variación se pierde al usar la media del género. Por eso conviene usar la biomasa en escala logarítmica y declarar el origen de cada valor (columna Biomass_level).

Código 
# Archivo descargado de figshare, guardado en la carpeta de este .qmd
archivo_adbt <- "ATLANTIC_DUNG_BEETLE_TRAITS_revised.csv"

if (file.exists(archivo_adbt)) {
  # Separador ";" y punto decimal. check.names = FALSE conserva los nombres
  # originales de las columnas (con espacios, paréntesis y unidades)
  adbt <- read.csv(archivo_adbt, sep = ";", check.names = FALSE,
                   fileEncoding = "UTF-8")

  # La columna 'species' trae subgénero entre paréntesis y autor, por ejemplo
  # "Dichotomius (Dichotomius) depressicollis (Harold, 1867)".
  # Esta función deja solo el nombre: "Dichotomius depressicollis"
  limpiar_nombre <- function(x) {
    x <- trimws(gsub("\\s+", " ", gsub("\\([^)]*\\)", " ", x)))
    vapply(strsplit(x, " "), function(p) {
      corte <- which(seq_along(p) > 1 & grepl("^[A-Z]|[0-9]{4}|&|,", p))
      paste(if (length(corte) > 0) p[seq_len(corte[1] - 1)] else p, collapse = " ")
    }, character(1))
  }

  adbt <- adbt %>%
    mutate(taxon    = limpiar_nombre(species),
           binomial = sub("^(\\S+ \\S+).*", "\\1", taxon),
           genero   = sub(" .*", "", taxon),
           biomasa  = coalesce(suppressWarnings(as.numeric(`Biomass (mean - g) (g)`)),
                               suppressWarnings(as.numeric(`Biomass (g)`)))) %>%
    filter(!is.na(biomasa))

  # Media por especie: solo nombres resueltos (sin sp., aff. ni cf.)
  adbt_sp <- adbt %>%
    filter(!grepl("sp\\.|aff\\.|cf\\.", taxon)) %>%
    group_by(binomial) %>%
    summarise(biomasa_sp = mean(biomasa), .groups = "drop")

  # Media por género: primero se promedia cada taxón, para que las especies
  # con muchos registros no pesen más que las demás
  por_taxon <- adbt %>%
    group_by(genero, taxon) %>%
    summarise(b = mean(biomasa), .groups = "drop")
  adbt_gen <- por_taxon %>% group_by(genero) %>%
    summarise(biomasa_gen = mean(b), n_taxa = n(), .groups = "drop")

  # Géneros de Chimichagua ausentes en la base: media de sus parientes de la
  # subtribu Scatimina (Ateuchini) que sí están (Vaz-de-Mello 2008)
  scatimina <- c("Trichillum", "Eutrichillum", "Pedaridium")
  b_scat <- por_taxon %>% filter(genero %in% scatimina)
  adbt_par <- tibble::tibble(genero = c("Scatimus", "Trichillidium"),
                             biomasa_par = mean(b_scat$b),
                             n_par = nrow(b_scat))

  rasgos_c <- rasgos %>%
    mutate(binomial = sub("^(\\S+ \\S+).*", "\\1", LatinName),
           genero   = sub(" .*", "", LatinName),
           resuelta = !grepl("sp\\.|aff\\.|cf\\.", LatinName)) %>%
    left_join(adbt_sp, by = "binomial") %>%
    mutate(biomasa_sp = if_else(resuelta, biomasa_sp, NA_real_)) %>%
    left_join(adbt_gen, by = "genero") %>%
    left_join(adbt_par, by = "genero") %>%
    mutate(Biomasa = coalesce(biomasa_sp, biomasa_gen, biomasa_par),
           Biomasa_log = log10(Biomasa),
           Origen_biomasa = case_when(
             !is.na(biomasa_sp)    ~ "especie",
             !is.na(biomasa_gen)   ~ paste0("media de género (", n_taxa, " taxones)"),
             !is.na(biomasa_par)   ~ paste0("media de Scatimina (", n_par, " taxones)"),
             TRUE                  ~ "sin dato"))

  print(rasgos_c %>% select(LatinName, Biomasa, Origen_biomasa), n = Inf)

  # Verificación: diferencia máxima con los valores del libro (debe ser < 0.00001)
  max(abs(rasgos_c$Biomasa - rasgos_c$Biomass_g))
} else {
  message("No se encontró ", archivo_adbt,
          ": se usan los valores de biomasa que ya trae la hoja rasgos.")
}

Esta plantilla muestra la estructura del piso completo y sirve para cualquiera de las cuatro bases. Los espacios ____ corresponden a decisiones del grupo: se reemplazan antes de ejecutar, y cada decisión se justifica en los métodos.

chequeo_arbol(____, tax)

biol <- tax %>%
  group_by(____) %>%
  summarise(across(where(is.numeric), sum), .groups = "drop") %>%
  tibble::column_to_rownames("____") %>%
  t() %>%
  as.data.frame()

# 3. Distancia funcional (Gower) con los rasgos elegidos
rasgos_df <- rasgos %>%
  select(LatinName, ____) %>%            # rasgos elegidos y justificados
  mutate(across(c(____), factor)) %>%    # los rasgos categóricos, como factor
  tibble::column_to_rownames("LatinName")
rasgos_df <- rasgos_df[rownames(biol), ] # mismo orden que las abundancias

stopifnot(identical(rownames(biol), rownames(dist_func)),

NotaSobre Jost

Con Jost = FALSE, Rao() devuelve la entropía cuadrática (para TD equivale al índice de Simpson), igual que en el Taller 2. Con Jost = TRUE convierte los resultados a números equivalentes, que se leen en las mismas unidades que los números de Hill de iNEXT3D() y facilitan comparar las tres dimensiones entre sí.

Qué se espera en el estudio de caso

El piso es obligatorio para todos los grupos: TD con iNEXT3D(), FD con Rao() y CWM, y PD con el árbol taxonómico. Con él, cada grupo trabaja las tres dimensiones sobre su propia base. El techo es opcional: mejora la calidad de los datos (más rasgos o una filogenia molecular) y, si se usa, se declara en los métodos. La ruta mínima y el nivel avanzado de cada dimensión se detallan en la rúbrica del estudio de caso. Lo que se tome de esta guía (funciones, fuentes de rasgos o de filogenia) se declara en los métodos.
