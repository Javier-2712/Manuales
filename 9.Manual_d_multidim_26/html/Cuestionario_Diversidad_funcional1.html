Cuestionario de profundización - FD

Código 
quarto::quarto_render("Cuestionario_Diversidad_funcional.qmd")

Propósito

Este cuestionario es una práctica de profundización después del Taller 2 (Diversidad Funcional con bloques A1, A2, B1 y B2). Se trabaja con comunidades tropicales de peces simuladas para fortalecer, en RStudio, las competencias para construir y defender un análisis de diversidad funcional (FD) y para el estudio de caso seleccionado. La secuencia reproduce la siguiente lógica metodológica:

datos → control de calidad → rasgos → distancia funcional → A1 → B1 → B2 → integración de los bloques.

Se debe conservar el código, ejecutar los bloques en RStudio, revisar los objetos creados y responder con base en sus propios resultados.

ImportanteRegla de trabajo

No se busca solamente obtener un número. Cada respuesta debe distinguir entre:

  1. qué se calculó;
  2. cómo se calculó;
  3. qué representa ecológicamente;
  4. qué limitación tiene la comparación.

3. Simulación de abundancias con estructura ecológica

Se asignan probabilidades de ocurrencia diferentes según el ambiente. Además, se introduce una diferencia deliberada en el esfuerzo de muestreo.

Código 
prob_base <- matrix(
  0.10,                                     # Probabilidad base uniforme de ocurrencia
  nrow = n_sp,                              # Una fila por especie
  ncol = 3,                                 # Una columna por ambiente
  dimnames = list(sp, c("BI", "AM", "LC"))  # Nombra filas (especies) y columnas (ambientes)
)

prob_base[1:20, "BI"] <- 0.55    # Las especies 1-20 son características de BI
prob_base[21:40, "AM"] <- 0.55   # Las especies 21-40 son características de AM
prob_base[41:60, "LC"] <- 0.55   # Las especies 41-60 son características de LC

prob_base[21:40, "BI"] <- 0.08   # Baja probabilidad de las especies de AM en BI
prob_base[41:60, "BI"] <- 0.04   # Probabilidad aún más baja de las especies de LC en BI

prob_base[1:20, "AM"] <- 0.08    # Baja probabilidad de las especies de BI en AM
prob_base[41:60, "AM"] <- 0.08   # Baja probabilidad de las especies de LC en AM

prob_base[1:20, "LC"] <- 0.06    # Baja probabilidad de las especies de BI en LC
prob_base[21:40, "LC"] <- 0.06   # Baja probabilidad de las especies de AM en LC

esfuerzo <- c(BI = 900, AM = 350, LC = 120)   # Define un esfuerzo de muestreo distinto por ambiente (a propósito)

abundancias <- map_dfc(
  seq_len(n_sitios),                        # Itera sobre cada sitio
  \(i) {
    amb <- meta$Ambiente[i]                 # Identifica el ambiente de ese sitio
    p <- prob_base[, amb]                   # Extrae el vector de probabilidades de ese ambiente
    lambda <- esfuerzo[amb] * p / sum(p)    # Reparte el esfuerzo total del ambiente entre las especies
    tibble(!!meta$Sitio[i] := rpois(n_sp, lambda))   # Simula abundancias con una distribución de Poisson
  }
) %>%
  as.data.frame()                           # Convierte a data.frame (formato que exige FD/iNEXT)

rownames(abundancias) <- sp                 # Asigna el nombre de especie como fila

6. A1 — Índices clásicos con dbFD()

6.1 Cálculo

Código 
fd_a1 <- 
  dbFD(
  x = fd_dist,             # Matriz de distancias funcionales (especie x especie)
  a = t(abundancias),      # Transpone: dbFD() exige sitios en filas y especies en columnas
  w.abun = TRUE,           # Pondera los índices por abundancia relativa
  calc.FRic = TRUE,        # Calcula la riqueza funcional (FRic)
  calc.FDiv = TRUE,        # Calcula la divergencia funcional (FDiv)
  calc.CWM = FALSE,        # No calcula las medias ponderadas por comunidad (CWM)
  corr = "sqrt",           # Aplica corrección de raíz cuadrada para garantizar euclidianidad
  m = 4,                   # Limita el cálculo de FRic a 4 ejes de PCoA (ver nota de rendimiento más abajo)
  messages = FALSE         # Suprime los mensajes de progreso de la función
)
AdvertenciaNota de rendimiento — por qué aparece m = 4

Los rasgos de esta simulación son independientes entre sí (cada runif()/rbinom() es una tirada aparte, sin correlación biológica real). Por eso, en el PCoA de la distancia de Gower casi todos los ejes (58 de 59) quedan con varianza positiva — a diferencia de rasgos biológicos reales, que suelen estar correlacionados y comprimir el espacio efectivo a pocos ejes.

Sin m = 4, dbFD() intenta la envolvente convexa de FRic en ese espacio de decenas de dimensiones, agota la memoria y bloquea RStudio sin mensaje de error — solo deja de responder. m = 4 limita el cálculo a los primeros 4 ejes, que es además la práctica recomendada por Villéger et al. (2008) cuando el número de especies no justifica más dimensiones. Con datos reales correlacionados (como en el Taller 2) este límite rara vez hace falta explícitamente, pero es buena práctica fijarlo siempre.

8. A2 — Partición de la diversidad funcional con Rao

A2 cambia la pregunta: en lugar de describir cada ambiente mediante varios índices por separado (como en A1), se busca descomponer la diversidad funcional en componentes alfa, beta y gamma mediante la entropía cuadrática de Rao.

\[\gamma = \overline{\alpha} + \beta_{add} \qquad \text{y} \qquad \gamma = \overline{\alpha} \times \beta_{mult}\]

8.1 De sitios a ambientes

Código 
biol_ambiente <- abundancias %>%
  as_tibble(rownames = "Species") %>%
  pivot_longer(-Species, names_to = "Sitio", values_to = "Abundancia") %>%
  left_join(meta, by = "Sitio") %>%
  group_by(Species, Ambiente) %>%
  summarise(Abundancia = sum(Abundancia), .groups = "drop") %>%
  pivot_wider(names_from = Ambiente, values_from = Abundancia, values_fill = 0) %>%
  column_to_rownames("Species") %>%
  as.data.frame()   # Especies (filas) x ambientes (columnas) — formato que exige Rao()

8.2 Ejecutar Rao()

Código
